# 📊 Financial Performance Analysis

## Retail Sales Data Analysis & Business Insights

An end-to-end **Data Analytics project** focused on analyzing retail sales and financial performance using **Excel, PostgreSQL, SQL, and Power BI**.

The project analyzes sales, profit, customers, products, categories, segments, and regional performance to identify business trends and generate actionable insights.

---

## 🎯 Project Objective

The main objectives of this project are:

* Clean and prepare raw retail sales data
* Analyze sales and profit performance
* Identify high-performing and under-performing regions
* Analyze category and segment performance
* Analyze customer and product performance
* Use SQL to answer business questions
* Create an interactive Power BI dashboard
* Generate business insights and recommendations

---

## 🛠️ Tools & Technologies

* **Microsoft Excel** – Data cleaning, Pivot Tables and analysis
* **PostgreSQL / SQL** – Data extraction, transformation and business analysis
* **Power BI** – Interactive dashboard and KPI visualization
* **CSV** – Dataset storage and processing

## 💡 Key Business Insights

The analysis was used to identify:

* High-performing and low-performing regions
* Profitable and less-profitable categories
